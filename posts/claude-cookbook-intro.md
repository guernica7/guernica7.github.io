# Claude Cookbook, 예제로 배우는 Claude API

Claude API로 뭔가 만들려고 할 때 공식 문서만으로는 감이 안 잡히는 순간이
있습니다. 레퍼런스는 파라미터를 알려주지만, "에이전트에 도구를 몇 개까지
물려도 되나", "긴 대화의 컨텍스트는 어떻게 관리하나" 같은 질문에는 답하지
않기 때문입니다. 이럴 때 보라고 Anthropic이 운영하는 곳이
[Claude Cookbook](https://platform.claude.com/cookbook/)입니다.

실행 가능한 노트북과 단계별 가이드 형태의 예제 모음집으로, 2023년부터
지금까지 꾸준히 갱신되고 있습니다. 소스는
[anthropics/claude-cookbooks](https://github.com/anthropics/claude-cookbooks)
저장소에 공개되어 있고 커뮤니티 기여도 받습니다.

## 무엇이 있나

예제는 카테고리 태그로 분류되어 있고 드롭다운 필터로 골라볼 수 있습니다.
주요 카테고리만 추리면 이렇습니다.

- **Tools / Agent Patterns**: 도구 호출과 에이전트 아키텍처. 계산기 도구
  같은 입문 예제부터 멀티 에이전트 오케스트레이션까지.
- **Claude Agent SDK**: 리서치 에이전트, 옵저버빌리티 에이전트, SRE
  에이전트 등을 하나씩 만들어 보는 연작 시리즈가 있습니다. Docker,
  Modal, Kubernetes에 에이전트를 호스팅하는 편까지 이어집니다.
- **RAG & Retrieval**: Text to SQL, 지식 그래프 구축, 출처 추적을 위한
  Citations 활용.
- **Multimodal**: 이미지 입력 기초, 문서 전사, 차트·그래프 읽기.
- **Evals / Observability**: 평가와 운영 모니터링. 만들고 끝이 아니라
  검증까지 다루는 게 특징입니다.

구현 언어는 대부분 Python이고, Pydantic, LlamaIndex, Pinecone, MCP 같은
주변 스택과의 통합 예제도 섞여 있습니다.

## 볼만한 가이드

페이지 상단에 추천으로 걸려 있는 가이드 몇 개가 특히 실전적입니다.

- **Programmatic Tool Calling**: 도구를 코드 실행 환경에서 프로그래밍
  방식으로 호출해 레이턴시와 토큰 소비를 줄이는 패턴.
- **Tool Search with Embeddings**: 도구가 수천 개로 늘어날 때 임베딩
  검색으로 필요한 도구만 동적으로 찾아 쓰는 방법.
- **Automatic Context Compaction**: 오래 도는 에이전트의 대화 히스토리를
  자동 압축해 컨텍스트 한계를 넘기는 기법.

셋 다 "API 호출 한 번"을 넘어서 에이전트를 실제 서비스 규모로 키울 때
부딪히는 문제들이라, 장난감 예제와 프로덕션 사이의 간극을 메워 줍니다.

## 어떻게 쓰면 좋나

문서처럼 처음부터 읽는 자료는 아닙니다. 지금 만들려는 것과 비슷한 예제를
카테고리 필터로 찾아서, 노트북을 열고 돌려보며 필요한 부분만 가져오는
식이 맞습니다. 예제마다 발행일이 붙어 있으니 같은 주제라면 최신 것부터
보는 편이 안전합니다. API와 SDK가 빠르게 바뀌는 만큼 오래된 예제는
현행 모델명이나 API와 다를 수 있기 때문입니다.

저는 로컬 에이전트 스택을 만지면서 에이전트 패턴 쪽 자료가 계속 필요했는데,
프레임워크 문서보다 이런 검증된 예제 모음이 출발점으로 낫다고 느꼈습니다.
다음에는 Agent SDK 시리즈 중 하나를 따라 만들어 보고 기록을 남길
생각입니다.
