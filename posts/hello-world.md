# 블로그를 새로 열었습니다

기록을 다시 시작합니다. 무겁지 않게, 마크다운으로 쓰고 `git push` 하면 배포되는
구조라 글쓰기 자체에만 집중할 수 있어요.

## 왜 VitePress인가

- 마크다운 파일이 곧 콘텐츠라 버전 관리가 자연스럽습니다.
- Vue 3 기반이라 필요할 때 컴포넌트로 확장할 수 있습니다.
- 코드 하이라이팅이 기본으로 훌륭합니다.

```ts
export function greet(name: string): string {
  return `안녕하세요, ${name}`
}
```
